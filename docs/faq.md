# 常见问题

**四位数字是什么？** 工具生成的防误触提示，仅用于当前模拟事务。

**活动账号是我在 Antigravity 的账号吗？** 界面只显示模拟身份，默认从模拟账号 01 开始。账号列表和活动状态在关闭程序后丢弃。

**浏览器能免除验证吗？** 是否要求选择账号、重新登录或进行二次验证由 Google 决定。

**能判断真实 Agent 是否空闲吗？** 工具只读取模拟状态。官方桌面的 Running Items 面板可供用户人工查看。

**怎么卸载？** 关闭工具后删除解压目录。如果手动创建过本工具的配置文件，可以同时删除 `%LOCALAPPDATA%\AGAccountSwitcherLite\settings.json`。
