# ADR 0002：由 .NET 离线模拟转向 Rust + Tauri 2 与系统凭据库架构

- **状态**：已采纳（2026-11-24）
- **取代 / 承接**：[ADR 0001：首版采用离线模拟](0001-simulation-only.md)

## 背景

`0.1.0` 初始提交 `db7e6b9` 采用 `.NET 10 WPF` 构建了四账号切换离线模拟原型以验证确认交互与故障状态机，但其真实切号交付进度为零。后续针对上游 `anglee0323/agy-switch v4.10.18` 的静态安全审计与真机调查表明：官方 Windows 桌面端通过当前用户 Windows Credential Manager 中的 `gemini:antigravity`（`CRED_TYPE_GENERIC`）条目持久化本地授权会话，在客户端正常退出后替换该条目并重启客户端可在有效期内省去重复浏览器登录。

同时，上游完整版包含自建 OAuth 回调服务器、明文 JSON 账号库、后台额度轮询、自动换号及实验性注入等超出本项目安全边界的模块，且其许可证为 `CC BY-NC-SA 4.0`。

## 决策

1. **技术栈与主仓归一**：将原 `.NET 10 WPF` 模拟原型归档至 `archive/dotnet-simulation-prototype` 分支；主仓切换为精简的独立 **Rust + Tauri 2 + 原生前端** 架构。
2. **系统凭据库原地事务**：不落盘任何明文账号 JSON，4 个账号槽位与恢复记录全部存入当前用户 Windows Credential Manager，使用 `CredWriteW` 原地覆盖并配合回读校验与启动失败自动回滚。
3. **1-A 窗口级安全关闭门禁**：移除抢占焦点的系统托盘 UI Automation 菜单操作，改为前端运行态确认 + `WM_CLOSE` 可见窗口关闭门禁；若可见窗口超时未关（如存在未保存提示）则立即中止切号绝不强杀，仅在可见窗口全部退入后台后收尾经路径和启动时间核实的驻留进程。
4. **许可证合规**：保留上游来源链并统一采用 `CC BY-NC-SA 4.0` 非商业同方式共享许可，完整披露全部裁剪与安全加固改动。
