# 0.1.0 初始化验收

本地验证日期为 2026-11-23，Windows 11 x64，.NET SDK 10.0.404，Windows Desktop Runtime 10.0.15。

| 项目 | 状态及证据 |
| --- | --- |
| Release 构建 | 已实现并测试。锁定还原与 NuGet Audit 通过。分析器启用，构建 0 警告、0 错误 |
| 核心业务 | 仅模拟，28 项 xUnit 测试全部通过。覆盖四账号操作、确认、并发、忙碌和未知状态拒绝、失败与恢复 |
| WPF 与会话内互斥 | 已实现并实测。启动可见窗口，读取四账号，第二进程拒绝并返回状态码 2，错码、取消、成功切换、重置、正常关闭和重启通过。也从解压构建产物运行了同一套检查 |
| 候选 ZIP | 已实现并测试。核对 Windows x64 ZIP、SHA-256、SPDX 2.2 清单和解压运行。微软 SBOM 工具验证了 12 个文件。框架依赖包没有第三方运行时 NuGet 包 |
| GitHub CI 与候选工作流 | 已配置。本地执行了对应的还原、构建、测试和打包步骤。GitHub 托管执行尚未核验 |
| 真实账号操作 | 仅提供官方界面操作指引。快速切换、免浏览器验证、真实任务探测和身份核验尚未实现。缺乏已确认且适用的官方契约 |
| 现有会话与工作区 | A–D 尚未实测。已记录相互独立的验证标准与批准流程 |
| 签名与公开发布 | 尚未实施。本轮为本地候选 |

锁定测试包的 NuGet 许可证元数据为 MIT 和 Apache-2.0。Microsoft Test SDK、测试平台及 Newtonsoft.Json 为 MIT。xUnit 套件的许可证为 Apache-2.0，xunit.abstractions 2.0.3 使用包内许可证 URL 作为依据。它们只用于测试，没有进 Windows ZIP。[xUnit 许可证](https://raw.githubusercontent.com/xunit/xunit/master/license.txt)

本轮安全复核结合应用源码、配置作用域、状态机测试和测试进程观察。无真实凭据、模型接入、遥测上传、任意命令或第三方进程控制入口。该记录覆盖 0.1.0，本地模拟通过不构成真实账号验收。
